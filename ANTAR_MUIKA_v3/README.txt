VIVA STOREFRONT — POLISHED PREVIEW
================================

Files:
- index.html: main storefront (loads css/style.css and js/app.js)
- viva-all-in-one.html: standalone HTML version with CSS and JavaScript embedded
- css/style.css: theme, layout, responsive styling and accessibility refinements
- js/app.js: product catalog and storefront interactions

Run:
1. Extract the ZIP.
2. Open index.html in a modern browser. Internet access is needed for Bootstrap, Bootstrap Icons, Google Fonts and remote product photos.
3. Or open viva-all-in-one.html as a single-file preview.

Included interactions:
- Responsive navigation and product categories/filters
- Product search and quick view
- Wishlist and shopping bag saved in browser local storage
- Quantity controls and shipping calculation
- Light/dark theme
- Newsletter demo feedback and demo checkout notice

Important:
This is a front-end prototype. It does not connect to a database, user account,
real payment gateway, shipping provider, order management system or newsletter
service. Checkout intentionally displays a demo notice and does not process
payments. Product data and customer reviews are sample content and should be
replaced with verified business information before launch.
